# Java лабораторні роботи з курсу "Кросплатформні засоби програмування"

## Призначення

Репозиторій містить Java-частину наскрізного навчального продукту для лабораторних робіт 1-5.

Поточна версія `1.1.0` розробляється для лабораторної роботи №2 і моделює обробку даних про автобусні рейси Львів-Жовква.

Проєкт розробляється поступово: кожна лабораторна робота додає нову функціональність, але має зберігати працездатність попередніх частин.

## Формат входу

Вхідний файл `data/input.csv` має кодування UTF-8. Один рядок відповідає одній поїздці, поля розділені крапкою з комою.

```text
vehicle;driver;km;fuelLiters;date
```

Приклад:

```text
Львів-Жовква АС-2;Петро Коваль;29.4;6.8;2026-09-10
```

Дані в `data/input.csv` є демонстраційним операційним журналом рейсів. Назви маршрутів узято як бізнес-контекст з напрямків від Львів АС-2, але водії, кілометраж, витрата пального та контрольні хибні рядки є навчальними даними для перевірки програми.

## Показники звіту

Програма має обчислити:

- кількість коректних записів;
- сумарний кілометраж;
- середню витрату пального на 100 км;
- найбільшу поїздку.

## Поточний стан

Maven-проєкт містить консольну програму. Вона читає `data/input.csv`, перевіряє записи, обчислює показники варіанта 7, друкує звіт у консоль і записує його в `out/report.txt`. У версії 1.1.0 кожен коректний рядок перетворюється на незмінний `Trip`; фабрика `Trip.fromCsv` перевіряє структуру CSV і числовий формат, а конструктор `Trip` підтримує інваріанти об'єкта. Некоректні рядки не входять до статистики. Незмінний record `MileageFuel` накопичує відстань і пальне та обчислює літри на 100 км.

Для рейсу потрібні непорожні `vehicle`, `driver` і `date`, скінченне `km > 0` та скінченне `fuelLiters >= 0`. `NaN` і нескінченність відхиляються. Показники та формат звіту на демонстраційному файлі залишилися такими самими, як у версії 1.0.0.

## Запуск

На Windows:

```powershell
.\mvnw.cmd test
.\mvnw.cmd verify
java -jar target\kzp-java-labs-volos-1.1.0.jar
```

Із власними шляхами до вхідного файла та звіту:

```powershell
java -jar target\kzp-java-labs-volos-1.1.0.jar --input data\input.csv --output out\report.txt
```

Версія програми:

```powershell
java -jar target\kzp-java-labs-volos-1.1.0.jar --version
```

На macOS та Ubuntu замість `.\mvnw.cmd` використовуйте `./mvnw`.
