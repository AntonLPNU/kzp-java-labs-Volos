# Java лабораторні роботи з курсу "Кросплатформні засоби програмування"

## Призначення

Репозиторій містить Java-частину наскрізного навчального продукту для лабораторних робіт 1-5.

Поточна версія розробляється для лабораторної роботи №1 і моделює обробку даних про автобусні рейси Львів-Жовква.

Проєкт розробляється поступово: кожна лабораторна робота додає нову функціональність, але має зберігати працездатність попередніх частин.

## Формат входу

Вхідний файл `data/input.csv` має кодування UTF-8. Один рядок відповідає одній поїздці, поля розділені крапкою з комою.

```text
vehicle;driver;km;fuelLiters;date
```

Приклад:

```text
Львів-Жовква АС-2;Петро Коваль;29.4;6.8;2026-09-10
```

Дані в `data/input.csv` є демонстраційним операційним журналом рейсів. Назви маршрутів узято як бізнес-контекст з напрямків від Львів АС-2, але водії, кілометраж, витрата пального та контрольні хибні рядки є навчальними даними для перевірки програми.

## Показники звіту

Програма має обчислити:

- кількість коректних записів;
- сумарний кілометраж;
- середню витрату пального на 100 км;
- найбільшу поїздку.

## Поточний стан

Підготовлено Maven-проєкт із консольною програмою. Програма читає `data/input.csv`, перевіряє записи, обчислює показники варіанта 7, друкує звіт у консоль і записує його в `out/report.txt`.

## Запуск

На Windows:

```powershell
.\mvnw.cmd test
.\mvnw.cmd package
java -jar target\kzp-java-labs-volos-1.0.0.jar
```

Із власними шляхами до вхідного файла та звіту:

```powershell
java -jar target\kzp-java-labs-volos-1.0.0.jar --input data\input.csv --output out\report.txt
```

Версія програми:

```powershell
java -jar target\kzp-java-labs-volos-1.0.0.jar --version
```

На macOS та Ubuntu замість `.\mvnw.cmd` використовуйте `./mvnw`.
